# BugTracker

BugTracker is a simple web-based application used to manage and track software bugs or issues.  
This project demonstrates basic Git and GitHub workflow operations including repository creation, cloning, committing, pushing, and handling merge conflicts.

---

## Features

- Basic BugTracker homepage
- HTML, CSS, and JavaScript structure
- Git version control integration
- Conventional commit usage
- Remote and local conflict handling practice
